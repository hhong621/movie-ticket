# Movie Ticket

Interactive desk of draggable movie tickets built with **React** and **Vite**. Each ticket shows poster art and opens a modal with fake showtime details. Includes holographic hover effect, uses [@paper-design/shaders-react](https://github.com/paper-design/shaders), optional UI sounds, and a light/dark theme. Based on this [Codepen](https://codepen.io/markmiro/pen/wbqMPa) by Mark Miro.

**Live:** [hhong621.github.io/movie-ticket](https://hhong621.github.io/movie-ticket/)
**Read more:** [blog post](https://hhong621.github.io/work/little_bits.html#ticket)

## Scripts

- `npm run dev` — local dev server  
- `npm run build` — production build  
- `npm run preview` — preview the build  
- `npm run deploy` — publish to GitHub Pages (`gh-pages` branch)
